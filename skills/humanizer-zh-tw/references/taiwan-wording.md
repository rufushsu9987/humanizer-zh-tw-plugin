# 台灣用語對照

本檔由 `humanizer-zh-tw` skill 在處理台灣繁體中文時讀取。AI 產生的繁體中文常是簡體稿轉字而來，字是繁體，用詞卻是中國用語；台灣讀者一眼就看得出來，比句式問題更明顯。

## 適用條件

- 只在目標是台灣繁體中文時使用。輸入是簡體中文，或使用者指定其他地區用語（香港、新加坡、中國）時，不套用本表。
- 只換用詞，不做簡繁轉換；字形與標點依 SKILL.md 的「輸出與檔案保護」處理。
- 不改受保護的內容：程式碼、指令、路徑、URL、API 與變數名稱、產品或服務的正式名稱、必須與實際介面一致的按鈕文字、直接引語、書名與專有名詞。
- 作者樣本或同一份文件中一致使用某個詞（例如公司規範統一寫「用戶」），保留作者的選擇，不逐一替換。
- 同一份文件內，同一概念換成一種說法後要前後一致。

## 二、依上下文判斷

這些詞在台灣也有正常用法，只有在左欄的意思下才換。

| 詞 | 換的情況 | 不換的情況 |
| --- | --- | --- |
| 質量 | 指好壞時換成「品質」 | 物理學的質量 |
| 程序 | 指電腦程式時換成「程式」 | 行政、法律上的程序 |
| 文件 | 指電腦檔案時換成「檔案」 | 指文書、文件資料 |
| 項目 | 指專案、計畫時換成「專案」 | 清單裡的項目 |
| 數據 | 一般資料換成「資料」 | 統計數字、量測結果，台灣也說「數據」 |
| 對象 | 程式語言的 object 換成「物件」 | 指人或目標對象 |
| 用戶 | 一般軟體使用者換成「使用者」 | 電信、公用事業的用戶，或作者一致使用時 |
| 支持 | 指功能支援時換成「支援」 | 表示贊同、支持某人 |
| 優化 | 技術文件可換成「最佳化」；一般文章可換成「改善、調整」 | 台灣口語已普遍使用「優化」，不必強改 |
| 視頻號、小程序等平台名 | — | 產品正式名稱，保留 |

## 三、網路口語與套話

這類詞多半出現在部落格和社群文章，通常要換成台灣慣用說法，或直接刪掉，不只是換詞：

- 「小夥伴們」「親」「寶子們」：改成「大家」「各位」，或直接刪掉。
- 「小編」：作者本人寫的就用「我」；若是品牌官方帳號固定的自稱，保留。
- 「靠譜」→「可靠」；「搞定」→「處理好」；「給力」→「很有幫助、很強」。
- 「賦能」「抓手」「落地」「打法」「閉環」「顆粒度」：先依 31 個檢查點的第 12 條判斷是不是空泛套話；確實有意思時，改成具體說法（「落地」→「實際執行、上線」）。
- 「點擊」：使用介面時台灣多說「點選、按」。
